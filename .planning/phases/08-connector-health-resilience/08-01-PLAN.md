<objective>
Build the connector circuit breaker and automated health check loop with auto-restart.

Purpose: Connectors currently have no automated health monitoring. The health check endpoint exists but is manual-only. This plan adds: (1) a per-connector circuit breaker that prevents hammering failing providers, (2) an automated health check loop that runs every 60s, and (3) auto-restart logic with exponential backoff for connectors that fail 3 consecutive polls.

Output: Two new modules (connector-circuit-breaker.ts, connector-health-loop.ts), integration into connector-engine.ts, and unit tests for both.
</objective>

Internal Map: `const circuits = new Map<string, ConnectorCircuitState>();`

Exported functions:
- `recordConnectorFailure(connectorId: string): ConnectorCircuitState` — pushes Date.now() to failureTimestamps, prunes entries older than FAILURE_WINDOW_MS, increments failures count from pruned array length, opens circuit if failures >= FAILURE_THRESHOLD (sets openUntil = Date.now() + HALF_OPEN_AFTER_MS)

- `getAllCircuitBreakerStates(): Map<string, ConnectorCircuitState>` — returns the entire circuits map
- `resetConnectorCircuitBreaker(connectorId: string): void` — deletes from circuits map

Constants:
```typescript
const HEALTH_CHECK_INTERVAL_MS = 60_000;  // 60 seconds
const CONSECUTIVE_FAILURE_THRESHOLD = 3;   // auto-restart after 3 failures
const BACKOFF_BASE_MS = 30_000;            // 30s base
const BACKOFF_MAX_MS = 300_000;            // 5 min max
```

Internal state:
```typescript
interface ConnectorHealthState {
  connectorId: string;
  status: "healthy" | "degraded" | "failed" | "circuit_open";
  consecutiveFailures: number;
  lastCheckAt: number;
  lastSuccessAt: number;
  latencyMs: number;
  restartCount: number;
  nextRestartAt: number;  // 0 if not in restart backoff
}
const healthStates = new Map<string, ConnectorHealthState>();
let loopInterval: ReturnType<typeof setInterval> | null = null;
```

Export `startConnectorHealthLoop()`:
1. If loopInterval already set, return (idempotent).
2. Call `runHealthChecks()` immediately.
3. Set `loopInterval = setInterval(runHealthChecks, HEALTH_CHECK_INTERVAL_MS)`.

Internal `async function runHealthChecks()`:
1. `const activeConnectors = await storage.getConnectors()` — get all connectors (filter status !== "inactive" in code).
2. For each connector:
   a. Check `isCircuitOpen(connector.id)` from circuit breaker module. If open, set state to "circuit_open", skip, log.
   b. Check if connector is in restart backoff (`nextRestartAt > Date.now()`). If so, skip.
   c. Get the plugin via `getPlugin(connector.type)`. If not found, skip.
   d. Call `plugin.test(connector.config as ConnectorConfig)` with a try/catch.
   e. On success (result.success === true):
     - Call `recordConnectorSuccess(connector.id)` from circuit breaker.
     - Call `storage.createConnectorHealthCheck({ connectorId: connector.id, orgId: connector.orgId, status: "healthy", latencyMs: result.latencyMs, credentialStatus: "valid" })`.
     - Update healthStates: status = "healthy", consecutiveFailures = 0, restartCount = 0, nextRestartAt = 0.
   f. On failure (result.success === false or caught error):
     - Call `recordConnectorFailure(connector.id)` from circuit breaker.
     - Increment consecutiveFailures in healthStates.
     - Call `storage.createConnectorHealthCheck({ connectorId: connector.id, orgId: connector.orgId, status: consecutiveFailures >= CONSECUTIVE_FAILURE_THRESHOLD ? "failed" : "degraded", latencyMs: result?.latencyMs ?? 0, errorMessage: result?.message ?? error.message, credentialStatus: "unknown" })`.
     - If consecutiveFailures >= CONSECUTIVE_FAILURE_THRESHOLD: compute backoff = `Math.min(BACKOFF_BASE_MS * Math.pow(2, restartCount), BACKOFF_MAX_MS)`, set nextRestartAt = Date.now() + backoff, increment restartCount, log auto-restart scheduled. Also update connector status to "error" via `storage.updateConnector(connector.id, { status: "error", lastSyncError: "Auto-restart: " + consecutiveFailures + " consecutive health check failures" })`.

Export `stopConnectorHealthLoop()`: clear interval, set loopInterval to null.

Export `getConnectorHealthStatus(): Map<string, ConnectorHealthState>`: returns clone of healthStates map.
