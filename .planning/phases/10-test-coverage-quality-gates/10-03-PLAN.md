<objective>
Add rate limiting consistency audit and org rate limit unit tests to verify all endpoints are protected.

Purpose: The org rate limit middleware is applied globally to `/api` routes, but there is no test verifying this registration or the middleware's bucket logic. Without tests, new routes could be registered outside the rate-limited scope, or changes to bucket logic could silently break rate limiting. This plan creates both an audit test (verifying coverage) and unit tests (verifying behavior).

Output: Rate limit audit test verifying global middleware registration and endpoint coverage, org rate limit unit tests covering plan tiers, bucket expiry, rate limit headers, and 429 responses.
</objective>

    This test performs a static audit of rate limiting coverage by:

    1. **Verify middleware registration** -- Read `server/routes.ts` source and verify it contains `app.use("/api", orgRateLimitMiddleware)` call. This ensures the global middleware is applied.

    2. **Verify exempt paths** -- The `orgRateLimitMiddleware` function checks for exact path matches: `/ops/health`, `/ops/ready`, `/ops/live`, `/health`. Verify these by calling the middleware with exempt paths and confirming `next()` is called without rate limit processing.

    3. **Document known exemptions** -- Maintain a list of intentionally exempt endpoints:
       - `/ops/health` - Kubernetes liveness probe (must not be rate limited)
       - `/ops/ready` - Kubernetes readiness probe
       - `/ops/live` - Kubernetes liveness probe (alternate)
       - `/health` - Legacy health check
       - `/api/billing/webhook` - Stripe webhook (authenticated via signature, not session)

    4. **Verify webhook rate limiting approach** -- The webhook endpoint at `/api/billing/webhook` does not use session auth (it uses Stripe signature verification). Verify it is still covered by the global IP-based rate limiter from `express-rate-limit` in `server/index.ts`. Document this as acceptable since Stripe controls the webhook delivery rate.

    5. **Cross-reference route registrations** -- Import route registration file list and verify all route files register under `/api/*` prefix (which is rate-limited). This is a sanity check that no routes are registered outside the protected prefix.

    The test approach uses a combination of:
    - Direct middleware invocation (calling orgRateLimitMiddleware with mock req/res)
    - Source code assertions (reading file contents to verify imports and registrations)
    - Documentation assertions (maintaining an EXEMPTIONS constant that must be kept in sync)

    ```typescript
    const DOCUMENTED_EXEMPTIONS = [
      { path: "/ops/health", reason: "Kubernetes liveness probe" },
      { path: "/ops/ready", reason: "Kubernetes readiness probe" },
      { path: "/ops/live", reason: "Kubernetes liveness probe (alternate)" },
      { path: "/health", reason: "Legacy health check" },
    ];

    describe("Rate Limit Coverage Audit", () => {
      it("orgRateLimitMiddleware exempts documented health check paths", async () => {
        for (const { path } of DOCUMENTED_EXEMPTIONS) {
          const req = mockReq({ path });
          const res = mockRes();
          const next = vi.fn();
          await orgRateLimitMiddleware(req, res, next);
          expect(next).toHaveBeenCalled();
          // Verify no rate limit headers were set (exempt paths skip rate limit processing)
        }
      });

      it("orgRateLimitMiddleware applies to non-exempt /api paths", async () => {
        const req = mockReq({ path: "/api/alerts", orgId: "test-org-audit" });
        const res = mockRes();
        const next = vi.fn();
        await orgRateLimitMiddleware(req, res, next);
        expect(next).toHaveBeenCalled();
        expect(res.setHeader).toHaveBeenCalledWith("X-RateLimit-Limit", expect.any(String));

        // This test ensures the DOCUMENTED_EXEMPTIONS list stays in sync

        const exemptPaths = DOCUMENTED_EXEMPTIONS.map(e => e.path);
        expect(exemptPaths).toContain("/ops/health");
        expect(exemptPaths).toContain("/ops/ready");
        expect(exemptPaths).toContain("/ops/live");
        expect(exemptPaths).toContain("/health");
      });
    });
    ```
