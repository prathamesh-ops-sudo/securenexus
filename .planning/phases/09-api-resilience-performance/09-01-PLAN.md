    4. Register event-bus listener at module level (after imports, before function definitions):
       ```typescript
       eventBus.on("entity:resolved", (event: BusEvent) => {
         if (event.orgId) {
           const removed = cacheInvalidate(`entity-graph:`);
           // Note: invalidates ALL entity-graph entries. For org-scoped invalidation,
           // we would need orgId in the cache key. Since buildCacheKey hashes params,
           // prefix-only invalidation clears all orgs. This is safe (cache refills on next request)
           // and simpler than maintaining an orgId->cacheKey index.

           }
         }
       });
       ```
       NOTE: Actually, for proper tenant-scoped invalidation per D4, restructure the cache key to include orgId as a prefix segment BEFORE hashing. Change getEntitiesForAlert and getEntitiesForIncident to accept orgId parameter or extract it from the query result context. This requires changing cache key construction to: `"entity-graph:" + orgId + ":" + alertId` (for alert) and `"entity-graph:" + orgId + ":" + incidentId` (for incident). The orgId can be obtained from the first entity result or passed as parameter.

       Simpler approach: Add an optional orgId parameter to both functions. If not provided, use a global prefix. Callers already have orgId in scope. Update the cache key to `entity-graph:${orgId || "global"}:alert:${alertId}` and `entity-graph:${orgId || "global"}:incident:${incidentId}`. Invalidation uses `cacheInvalidate("entity-graph:" + event.orgId + ":")`.
