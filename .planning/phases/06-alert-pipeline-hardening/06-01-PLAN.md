<objective>
Add temporal deduplication to the alert ingestion pipeline so duplicate alerts within a configurable time window update the existing record (lastSeenAt, occurrenceCount, status=deduped) instead of creating duplicates.

Purpose: Production alert pipelines receive the same alert multiple times. Without temporal dedup, the database fills with duplicates that obscure real signal and waste correlation resources.
Output: Modified schema with occurrenceCount, temporal dedup logic in upsertAlert, updated ingestion route, and unit tests.
</objective>
