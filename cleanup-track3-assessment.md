# Cleanup Track 3 — Dead Code Removal Assessment

**Branch:** `devin/cleanup-track3-deadcode`
**Base:** `devin/1775462796-platform-seed`
**Date:** 2026-04-20

## Methodology

1. **Attempted `knip` first.** Knip hung on the full scan of this large codebase (633 source files, 110+ routes, 244KB `server/storage.ts`). Abandoned after >10 min with no output.
2. **Switched to targeted manual analysis** with `ripgrep`:
   - Step 1 — Extract every `from "…"`, `import("…")`, and `require("…")` specifier from every `.ts/.tsx/.js` file under `server/`, `shared/`, `client/`, `e2e/`, `scripts/`, `script/`, `agent/`.
   - Step 2 — Reduce to the trailing path segment (the candidate filename) and dedupe.
   - Step 3 — For every non-entry-point, non-test, non-`index` source file, check whether its stem (or stem + extension) appears in the imported-basename set.
   - Step 4 — For each surviving candidate, run a **stricter second pass** looking for:
     - `from "…/stem"` or `import("…/stem")` (exact path end match)
     - JSX `<PascalCase` usage of the file's PascalCase form (e.g. `alert.tsx` → `<Alert ` / `<Alert/>` / `<Alert>`)
   - Step 5 — For every remaining candidate, **manually inspect**:
     - Dynamic imports that could use computed specifiers
     - Re-exports via barrels (`server/storage/index.ts`, `shared/schema.ts`)
     - String-based route registration
     - Vite/Webpack config references
     - Framework conventions (React auto-discovery not used here — `client/src/App.tsx` registers every page explicitly via `lazy(() => import("@/pages/..."))`)
     - Whether the "ref" shown in broader grep is a false positive on a common word in docs/markdown or a Drizzle schema export with the same noun (e.g. `ransomwareIndicators` table is exported, but the `server/storage/ransomware.ts` storage module that wraps it is not imported anywhere).

3. **Entry points & auto-discovered files excluded from orphan consideration:**
   - `server/index.ts`, `server/routes.ts`, `server/routes/index.ts`
   - `client/src/main.tsx` (referenced from `client/index.html` `<script type="module" src="/src/main.tsx">`), `client/src/App.tsx`
   - `shared/schema.ts`, `shared/ocsf.ts`
   - All `*.config.ts`/`.js`, `commitlint.config.js`, `tailwind.config.ts`
   - All `*.test.ts` / `*.spec.ts` / `__tests__/**` / `fixtures/**` / nested `index.ts` barrels
   - E2E specs under `e2e/` (Playwright auto-discovers via `playwright.config.ts`)

## Scope Boundary — Not Attempted

- **Unused exports inside live files.** `server/storage.ts` (244KB) and many route files almost certainly contain unused internal exports, but rigorous removal requires a working `knip` run or compile-level dead-export analysis. Deferred; HIGH risk of false positives without a working tool run.
- **Unused dependencies in `package.json`.** Out of scope for this track (will need a separate pass once `knip` works).
- **Docs/MD files.** Per user standing instruction, docs files are not deleted.
- **Orphaned root-level scripts.** No backup/temp/`.bak`/`.old`/`~`/numbered-copy files were found. `script/` vs `scripts/` is intentional (both referenced by `package.json`).
- **Migrations folder.** Not touched — migrations are historical artifacts even if the SQL is "no longer run".
